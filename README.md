library-api



Справочник книг. Сами книги можно добавлять, удалять, смотреть и менять через REST API или через страницу в браузере.



Что внутри



Java 17, Spring Boot 4.1.1

Spring Data JPA и PostgreSQL

Flyway для миграций базы

Проверка входных данных через Bean Validation

Тесты на JUnit 5, Mockito и MockMvc

Фронтенд на HTML, CSS и JavaScript без фреймворков



Структура



controller — принимает запросы

service — бизнес-логика, например проверка занятого ISBN

repository — работа с базой

entity — сущность `Book`, которая соответствует таблице

dto— объекты для запросов и ответов

mapper — перевод между сущностью и DTO

exception — свои исключения и единый обработчик ошибок



Что нужно для запуска



JDK 17 или новее

PostgreSQL

Maven ставить не нужно, в проекте есть mvnw



Настройка базы



1\. Создайте базу library\_db.

2\. Пароль от базы не хранится в коде. Его нужно передать через переменную DB\_PASSWORD.



Запуск в PowerShell:



powershell

$env:DB\_PASSWORD="ваш\_пароль"

.\\mvnw.cmd spring-boot:run





Flyway при старте сам создаст таблицу book.



Тесты



powershell

.\\mvnw.cmd test





Тесты не требуют запущенной базы.



Эндпоинты



| Метод  | Путь        | Что делает        | Коды ответа            |

|--------|-------------|-------------------|------------------------|

| GET    |  /books     | список книг       | 200                    |

| GET    | /books/{id} | одна книга        | 200, 404               |

| POST   | /books      | добавить книгу    | 201, 400, 409          |

| PUT    | /books/{id} | изменить книгу    | 200, 400, 404, 409     |

| DELETE | /books/{id} | удалить книгу     | 204, 404               |



Пример тела для `POST /books`:



json

{

&#x20; "title": "Мастер и Маргарита",

&#x20; "author": "Булгаков",

&#x20; "year": 1967,

&#x20; "isbn": "978-5-17-000001-2",

&#x20; "publisher": "АСТ",

&#x20; "genre": "Роман"

}





Поля title и author обязательны. Год должен быть от 1400 до 2100. ISBN не может повторяться.



Ошибки



Все ошибки приходят в одном формате:



json

{"status": 404, "message": "Книга с id 999 не найдена"}





Фронтенд



После запуска приложения откройте в браузере:



http://localhost:8080/frontend.html



Там можно добавлять, редактировать и удалять книги, а также искать по названию и автору.
